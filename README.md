# BMMotion — site

Site estático (HTML, CSS e JS puros) de vídeos cinematic, shorts e intros para MU Online.
Publicado no Netlify: https://bmmotion.netlify.app

- Sem etapa de build: o Netlify publica a raiz do repositório (`netlify.toml`).
- Cores e tipografia: `assets/css/style.css` (bloco `:root`).
- Interações: `assets/js/main.js`.
